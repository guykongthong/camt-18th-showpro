# SE CAMT ShowPro Arcade — app

Vue 3 + Vite build of the arcade-themed capstone showcase. See `../CLAUDE.md` for
architecture, visual language, and the development workflow (branching, CI).

```bash
npm install
npm run dev        # local dev server
npm run lint        # eslint + prettier
npm run typecheck   # vue-tsc against src/**/*.{js,vue}
npm run build        # production build
```
